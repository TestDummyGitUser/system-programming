### Задание №1
**Цель заданя:** реализовать функцию деления на C, заставив компилятор использовать инструкцию `idiv`.
```c
// Код на C:
long pw1(long a, long b){
    return a / b;
}

// Код на assembly gcc:
mov     rax, rdi
.loc 1 2 14 view .LVU3
cqo
idiv    rsi
.loc 1 3 1 view .LVU4
ret

// Код на assembly clang:
mov     rax, rdi
.loc    1 2 14 prologue_end
mov     rcx, rdi
or      rcx, rsi
shr     rcx, 32
je      .LBB0_1
cqo
idiv    rsi
.loc    1 2 5 is_stmt 0
ret
```
**Исходный код:** https://godbolt.org/z/hMEca9KrG

short pw2(short a){

        ret

### Задание №4
**Цель заданя:** узнать почему инструкция `lea` может выполнять сложение и умножение одновременно, но не может выполнять вычитание или деление. Реализовать в *Godbolt* функцию, где компилятор использует `lea` для умножения на `3`, `5` и `9`.
```c
// Первый вариант
// Код на C:
long pw4_1(long a, long b){
    return a*2 + b;
}

// Код на assembly gcc:
pw4_1:
        lea     rax, [rsi + 2*rdi]
        ret



// Второй вариант
// Код на C:
long pw4_2(long a, long b){
    return a*3 + b;
}

// Код на assembly gcc:
pw4_2:
        lea     rax, [rdi + 2*rdi]
        add     rax, rsi
        ret
```

**Вывод:** Команда `lea` предназначена для быстрого вычисления адресов памяти, поэтому её аппаратная схема жестко привязана к формуле адресации процессора, которая использует операцию сложения и операцию умножения (только на `1`, `2`, `4` или `8`).

**Исходный код:** https://godbolt.org/z/PEhsKdxz6

*   **O1:** https://godbolt.org/z/xrbzbx6v8
*   **O2:** https://godbolt.org/z/T5nfTzq5v
